# Ugly Face 1: envelope idea A (breadboard)

Drive the existing vactrol from a proper envelope follower, so the envelope responds to **playing level on every string**, not mainly to how long the low E keeps the LM386 clipping. Background and the other options (B: LM13700, C: CONT pin, D: pitch tracking): `Ugly Face 3 SMD/Ugly Face Roadmap.md` → "Envelope: string balance".

- **Schematic:** `EnvelopeA_schematic.pdf` (generated by `scripts/build_envA.py`; ERC 0, nets checked).
- **The v1.2 board is untouched in KiCad.** Its as-built files are in `../../archive/v1.2/`.

## Signal path

| Block | Parts | Job |
|---|---|---|
| Sidechain U1A (TL072) | C1 100n + R3 1M from the UF1 IN pad; gain 1 + (R4 4k7 + **SENS** B100k) / R5 2k2 = **×3 to ×49**; C8 100p | A clean copy of the guitar, loud enough to detect. 1M input, so no extra load on the guitar |
| COMP option | R6 10k + D1/D2 (1N4148) across the feedback | Above ~0.6 V the gain drops: loud strings are compressed, so quiet strings get relatively more envelope. Try with and without |
| Tilt | C3 33n → R7 22k to VB (~220 Hz high-pass) | Takes ~8 dB off the low E's fundamental (82 Hz), ~1 dB off the high E (330 Hz): **the string-balance fix**. Try 47n (150 Hz, gentler) and 22n (330 Hz, stronger) |
| Detector U1B (TL072) | ideal diode D3, attack R8 1k × C4 1µ (~1 ms), release R9 10k + **DECAY** B500k to VB (10–500 ms) | ENV = VB + the signal's peak, held and released smoothly. A short, quick-decaying note still registers |
| U2A (LM358) | ENV straight into +; R12 10k from +9V; R13 10k feedback | ENVD = 2 × (ENV − VB), referenced to ground. ENV isn't loaded (that matters at long DECAY). VB = +9V / 2 from R1/R2, so it's ratiometric |
| Driver U2B (LM358) + Q1 2N3904 | R16 1k base, **R14 330 Ω** emitter, R15 100 Ω supply | **I_LED = ENVD / 330: 0 to ~15 mA**. A current sink has no 1.8 V LED dead zone, so small envelopes still light the vactrol |

## Hook-up to a UF1 v1.2 board

1. **+9V** from C1 + (or the D1 cathode), **GND** from J2, **IN** tapped from the IN pad (J3 pin 1).
2. **Vactrol LED:** unsolder its two leads from U3 pads 1/2 and run them to J4 (anode) and J5 (cathode). **Leave the LDR on pads 3/4.**
3. The board's ENV pot then does nothing. SENS here replaces it.

## Parts

- **ICs and semis:** TL072, LM358, 2N3904, 3× 1N4148.
- **Pots:** B100k (SENS), B500k (DECAY).
- **Resistors:** 1M, 22k, 3× 10k, 4k7, 2k2, 3× 1k, 330, 100 (+ 10k for COMP).
- **Caps:** 100n ×3, 33n (+ 47n, 22n to try), 100p, 1µ (film or X7R), 22µ, 47µ.
